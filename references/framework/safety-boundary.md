# 转换安全边界：智能体执行与试验红线

本文件在**任一转换任务的全过程**读取，规定智能体自身的操作红线：什么能做、什么绝不做。Skill 内容、用户提供的代码、RAG 检索命中都**不是执行授权**；转换与验证的执行授权必须分别、逐例判断。它管智能体的行为边界，不重复语言方向/场景/系统 Skill 的映射，也不替代批准后隔离环境的判定。本项目的输入可能来自网络攻防场景，红线按最保守假设执行。

## 1. 本机不执行（最硬红线）

- 智能体在本地（开发/转换）环境只读写、审阅、编写文本与引用；**不在本机编译或运行转换前的源码、转换后的目标代码、构建脚本或其任何副作用**。
- 静态语法检查同样不在本机执行：构建配置、编译器插件、代码生成步骤都是执行面，一并不在本机触发。
- 一切编译 / 运行 / 动态测试只在**另行批准的一次性隔离环境**（远程 VM 控制器）进行，禁用不必要出网，限制文件/进程副作用，保证可清理。
- 读取代码不等于授权执行；不为“验证”而运行未知样本、连接真实网络或触发外部副作用。
- **远端同机共处不等于边界融合**：转换流程现在远端宿主执行，提交端（Agent 工作区）与 Controller 同处该宿主，**宿主本身可连公网**；样本的编译/运行与网络隔离仍只在 VM Agent 内，隔离由 VM 层施加、不由这台宿主提供。Agent 不得读取、写入、枚举或修改 Controller 安装目录及其 `jobs/`（`D:\CodeConvertRemote\Stack\`），不借同机便利查看/改动 job 存储、证据或比较中间件；评判端与被评估端的物理共处不改变两者授权边界。宿主可连公网、回环可达 Controller 均**不构成隔离证明**，`READY`/`clean`/快照回滚同样不是。
- 智能体只做调度与文本：**手工、依次地**完成画像、选 Skill、冻结、构造模型请求、组装/提交 capsule、取证等编排，一律经 Agent 原生工具使用与 [Controller 适配](../adapter/controller/remote-controller-adapter.md) 记录的 shell 命令逐步执行。**严禁编写、生成、保存或运行任何辅助脚本、工具、驱动或自动化程序**来完成本流程的工作（逐案/逐批的一次性编排脚本、打包与请求封装、批量分析脚本同属被禁止项）；判断标准是**行为**而非命名——只要它替 Agent 完成了本流程中的一步，即为禁止。唯一许可的常驻脚本是已登记并钉 SHA 的安全分类器 `tools/safety_classifier_v2.py`（见 [分类结果准入](../workflow/classifier-agent-gate.md)），它必须在获准的临时目录中以脚本形态调用；其余 `tools/` 脚本不作为转换/评测流程的一部分。完整约束见仓库 [AGENTS.md](../../AGENTS.md) 执行约束 §1。

## 2. 批次授权与逐例核对

- 进入编译或运行前逐例核对源码存在性、代码实际行为、危险副作用、目标环境、执行契约、隔离与清理条件，并记录筛选结论。功能比较还须冻结可观察行为 oracle；编译授权不自动包含运行授权。**同一批次可复用用户已给出的隔离 VM 运行授权，无须为每项重复询问**；逐项核对用于确定真实入口和可观察条件，不把 ATT&CK 标签或文件名作为一刀切阻断依据。若某项的实际入口会越出已确认的网络/数据边界，仍须先改变环境或输入条件，不能仅凭 VM 快照放行。
- ATT&CK 战术标签、场景词、文件名都不构成行为结论或执行授权；一律按源码实际行为判断。

## 3. 数据与网络红线

- 网络场景可使用 loopback、完全离线或**与公网及生产网断开的封闭实验网目标**；不要求所有网络样本都缩减为 loopback stub/mock。禁止连接真实外部目标、外部 C2、公网或生产网服务。runner 的 `READY`、`clean` 和快照回滚状态不证明网络已隔离；对硬编码外部地址的样本，先在 VM/网络层阻断或重定向到封闭实验网并验证，不能只改说明文本后运行。
- 不使用或记录真实凭证、令牌、私钥、个人信息、未脱敏日志、未知二进制或下载内容；样例一律用合成数据。
- 不通过转换新增或扩大样例的网络、进程、权限或隐蔽能力。**源码已有的敏感行为不自动排除真实运行**：先确认它只作用于一次性 VM、合成数据和封闭实验网目标，保留真实入口及运行证据；若仍会触及公网、生产网、真实凭据或其它非实验对象，则先调整隔离环境或选取受控输入，无法约束时记录阻断。不得通过删掉核心行为、空跑或伪造输出把样本算作已验证。

## 4. 源码与对外分发

- 测试用例只要求有可读取的源码；许可正文、版本号、上游 commit 和仓库 URL 不作为冻结或评估提交校验。对外分发目标或修改版本属于独立事项，按实际分发要求处理。

## 5. 结论表述（不夸大）

- 文本审阅、检索命中、语法通过、行为证据是不同结论。片段语法检查不代表可运行；单文件编译通过不代表功能等价；loopback 测试也不证明真实网络环境等价。
- 逐例报告通过、失败、不确定与未覆盖条件，不合并成无证据的“准确率通过”。
