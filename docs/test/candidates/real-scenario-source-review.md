## 代表性功能义务：HTTP 上传候选（设计输入，未获准执行）

若未来找到许可/版本明确的同类真实源码，转换前至少冻结以下可观察义务：

1. 正常路径：只从 case 私有的合成文件读取固定字节，受控 loopback 接收端观察到一次 POST；方法、路径、请求体长度和字节摘要与源端一致，目标不得新增外联。
2. 失败路径：文件不存在或不可读时不发送请求；接收端拒绝或超时时报告失败并关闭句柄。单纯进程退出码不能作 oracle，因为当前旧副本成功和失败都返回 0。
3. 证据边界：需要接收端请求日志/摘要与两侧输出、文件访问、超时记录；当前 Controller 的 network 维度是契约字段而非可用 Collector，未补观察前功能结论须为 `INCONCLUSIVE`/`UNVERIFIED`。
4. 安全边界：原件写死的非 loopback 接收端和主机文件路径不得进入任何执行 capsule；改变输入目标必须作为可追溯的 case 适配，与原件分开保存并单独审阅。
