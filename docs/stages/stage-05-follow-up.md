# 阶段 05：后续能力决策

> 状态：规划中

当前 Skill 拓展不以阶段 03/04 为前置条件。依据[当前阶段](final-output-compile/阶段方案.md)最终交付版本的编译失败归因选择新知识；功能正确性与 RAG 是否重启，则在观测能力、样例和逐例授权具备后再决定：

- 若 RAG 对逐例下游结果有可重复的净收益且来源可靠，再决定最小索引、更新和调用方式；否则保留直接 Skill/文件检索。
- 若四例发现明确系统迁移知识缺口，优先补对应 source OS → target OS Skill，再扩展样例。
- 若长文件结构覆盖仍失败，先修订长文件工作流和分段边界规则；不可把失败自动归因于 RAG。
- 更广方向、完整 ATT&CK 场景覆盖及性能目标另行建立问题集和验收定义，不外推四例结果。
