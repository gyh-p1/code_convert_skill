## 必须补齐的试验材料

- 来源：合成样例标记、许可证/使用授权与 ATT&CK 分类（若适用；不从标签反推行为）；
- 范围：源/目标语言、OS、架构、编译器/标准、真实行数和 token 数；
- 行为 oracle：源端可观察输出、错误、文件/网络/进程状态和允许的平台差异；
- 风险审阅：网络 loopback 限制、临时目录边界、固定 helper 命令和清理条件；
- 隔离方案：获批的源/目标执行环境、出网限制和每轮重置办法。

正式 No-RAG 基线的 oracle 必须在正式转换前冻结；用户明确要求的文本级探索草稿可先于审批生成，但须标注为非基线。无 RAG / RAG 复用同一份源材料；目标文件存于 `output/no-rag/` 与 `output/rag/`。没有隔离环境或 oracle 不明确时，不编译/运行，也不把探索稿列入试验结果。
