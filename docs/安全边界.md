# 安全边界（已迁移至产品树）

> 系统/运行时安全边界已迁至随产品安装的 [`references/framework/safety-boundary.md`](../references/framework/safety-boundary.md)（权威版本）；根 [`SKILL.md`](../SKILL.md) 的 §安全边界 给出内联红线。
> 本文件不再承载系统红线，只在开发期保留，用于记录本项目试点的审批状态与阅读指引。

## 为什么迁移

`docs/` 只在开发期使用、不随产品安装；而安全边界是**运行时系统必须遵守的红线**，必须放进随 Skill 一起安装的树（`references/`），否则产品装到智能体上就读不到。凡“转换系统本身”要遵守的规则都放 `references/`，不放这里。

## 试点审批状态（开发期上下文）

- 固定四例无 RAG/RAG 对照专项已取消；当前阶段与退出条件以[项目开发规范第 3 节](项目开发规范.md#当前开发阶段与退出条件)为准。历史数据集中的 run 不因此获得新的执行授权。
- 任何编译或运行仍须按 [`references/framework/safety-boundary.md`](../references/framework/safety-boundary.md) 逐例核对源码存在性、代码行为、危险副作用、目标环境、执行契约和清理条件，并在一次性隔离环境进行。功能比较另外冻结行为 oracle；获批编译不自动授权运行。
